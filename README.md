# N-Body Simulator

Интерактивный 2D-симулятор гравитационного взаимодействия N тел на Python + Pygame.

## Возможности

- Добавление тел мышью с заданием начальной скорости перетаскиванием
- Три численных интегратора: Euler, Leapfrog (Verlet), RK4
- Визуализация орбитальных следов
- Упругие столкновения тел
- Сохранение и загрузка сцен в JSON
- Встроенные сцены: двойная звезда, планета+солнце, задача трёх тел, галактика и др.

## Установка

```bash
git clone <repo>
cd nbody-sim
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install numpy>=1.26 pygame>=2.5
```

## Запуск

```bash
# Стартовый экран выбора сцены
python main.py

# Сразу загрузить сцену и задать имя файла сохранения
python main.py --scene two_body --name my_save
```

## Управление

### Симуляция

| Клавиша | Действие |
|---------|----------|
| `Space` | Пауза / продолжить |
| `C` | Очистить сцену |
| `Q` | Сохранить текущую сцену |
| `L` | Загрузить сцену |

### Добавление тел

Тела добавляются только на паузе. Зажмите ЛКМ в точке появления тела и потяните — длина и направление линии задают начальную скорость.

| Клавиша | Действие |
|---------|----------|
| `,` / `.` | Масса нового тела ×0.8 / ×1.25 |
| `V` / `B` | Масштаб скорости ×0.8 / ×1.25 |

### Интегратор

| Клавиша | Метод |
|---------|-------|
| `1` | Euler (быстрый, неточный) |
| `2` | **Leapfrog** (рекомендуется) |
| `3` | RK4 (точный, медленнее) |

### Параметры симуляции

| Клавиша | Действие |
|---------|----------|
| `[` / `]` | Шаг времени `dt` ×0.8 / ×1.25 |
| `-` / `=` | Смягчение `eps` ×0.8 / ×1.25 |
| `T` | Следы вкл/выкл |
| `P` | Столкновения вкл/выкл |

### Навигация

| Клавиша | Действие |
|---------|----------|
| `Z` / `X` | Зум +10% / −10% |
| `W` `A` `S` `D` | Сдвиг камеры |

## Формат сцены

```json
{
  "G": 1.0,
  "eps": 0.005,
  "dt": 0.005,
  "bodies": [
    {"x": -0.5, "y": 0.0, "vx": 0.0, "vy": 0.6, "m": 1.0},
    {"x":  0.5, "y": 0.0, "vx": 0.0, "vy": -0.6, "m": 1.0}
  ]
}
```

Файлы сцен хранятся в папке `scenes/`. Поле `radius` не сохраняется — вычисляется из массы автоматически.
